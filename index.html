nsb-3nr-mods — opkg feed

Elecom NSB-3NR (OpenWrt/uClibc ARMv7) 用の自作 ipk 配布ページです。 ソースとドキュメントは GitHub リポジトリ を参照してください。

NAS での設定

# /etc/opkg.conf に追加
src/gz nsb3nr https://nsmr0604.github.io/nsb-3nr-mods/

opkg update
opkg list | grep openssl-uclibc-bp
opkg install openssl-uclibc-bp
